# Code of Conduct

## The standard

Be respectful. Assume good faith. Critique the work, not the person.

Unacceptable: harassment, personal attacks, sustained disruption, publishing others' private information.

## Scope

Applies in this repository and in any space where someone represents the project.

## Enforcement

Report to **<a real contact — an unattended address makes this document worse than nothing>**.

Reports are handled confidentially. Responses range from a warning to a permanent ban, depending on severity and pattern.
